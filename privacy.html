Kebijakan Privasi

Bagaimana Buku Kas memperlakukan data Anda. Singkatnya: data keuangan tetap di perangkat Anda dan tidak dikirim ke pengembang.

Ringkasan: Buku Kas tidak menyediakan akun, tidak memakai server pengembang, tidak menampilkan iklan, dan tidak mengumpulkan data analitik. Data keuangan Anda disimpan di perangkat Anda sendiri.

1.Data yang Disimpan di Perangkat

Aplikasi menyimpan data berikut secara lokal di database SQLite perangkat:

  • Transaksi keuangan, dompet, kategori, periode, dan riwayat tutup buku.
  • Anggaran, transaksi berulang, dan pengaturan aplikasi.
  • Hash PIN aplikasi beserta salt. PIN asli tidak disimpan sebagai teks biasa.
  • Preferensi biometrik, pengingat, tema, dan format periode.
  • Foto bukti transaksi yang Anda lampirkan, disimpan sebagai file lokal.

Data tersebut tidak dikirim ke pengembang atau pihak ketiga. Data tetap berada di perangkat sampai Anda menghapus aplikasi atau membersihkan data aplikasi.

2.Data yang Tidak Dikumpulkan

Buku Kas tidak mengumpulkan atau menjual:

  • Nama, alamat email, nomor telepon, atau data akun pengguna.
  • Lokasi, kontak, mikrofon, atau akses kamera tanpa tindakan Anda.
  • Data analitik, iklan, identitas perangkat, atau riwayat penggunaan.
  • Data keuangan ke server pengembang atau penyedia layanan pihak ketiga.

3.Izin Perangkat

Aplikasi dapat meminta izin berikut, hanya untuk fungsi yang Anda aktifkan:

  • Notifikasi untuk pengingat harian lokal.
  • Biometrik untuk membuka kunci aplikasi di perangkat yang mendukung.
  • Exact alarm untuk menjadwalkan pengingat pada waktu yang dipilih.
  • Kamera atau galeri hanya saat Anda memilih foto bukti transaksi.
  • Internet diperlukan oleh lapisan WebView aplikasi. Aplikasi tidak mengirim data ke server pengembang.

Anda dapat menolak atau mencabut izin melalui pengaturan Android.

4.Backup, Ekspor, dan Berbagi

Fitur backup JSON, ekspor CSV/PDF, ekspor foto transaksi, dan berbagi file hanya berjalan ketika Anda memintanya. File dibuat di perangkat lalu disimpan atau dibagikan melalui sistem operasi. Pengembang tidak menerima salinan file tersebut.

Backup JSON tidak menyertakan hash PIN maupun file foto transaksi. Restore mempertahankan kredensial perangkat yang sedang aktif.

5.Keamanan

PIN aplikasi disimpan sebagai hash PBKDF2-SHA256 dengan salt acak. Auto backup Android dinonaktifkan agar data tidak otomatis disalin ke layanan cloud perangkat. Meskipun demikian, tidak ada sistem yang sepenuhnya bebas risiko. Lindungi perangkat dan simpan file backup Anda di tempat yang aman.

6.Retensi dan Penghapusan

Data lokal tetap tersimpan selama aplikasi terpasang. Menghapus aplikasi atau membersihkan data aplikasi akan menghapus database lokal. File backup yang pernah Anda buat dikelola sepenuhnya oleh Anda. Karena pengembang tidak menyimpan data di server, tidak ada data server yang perlu dihapus.

7.Anak-anak

Buku Kas tidak ditujukan untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data pribadi anak.

8.Perubahan Kebijakan

Kebijakan ini dapat diperbarui jika fitur atau praktik data berubah. Versi terbaru akan dipublikasikan di halaman ini beserta tanggal berlakunya.
